Vocabulary (Nature/Animals)
Rounds / Imikino
You will play exactly 6 rounds: 3 Beginner (6 cards) then 3 Advanced (10 cards).
Uzakina imikino 6: 3 yoroshye (amakarita 6) hanyuma 3 ikomeye (amakarita 10).
How to Play / Uko bakinwa
  1. Tap one card to reveal and read the word. Kanda ikarita 1 uyihindure usome ijambo.
  2. Tap a second card. Kanda ikarita ya 2.
  3. Wait 2 seconds. Match = stay open ✅. Not match = close ❌. Tegereza amasegonda 2. Birahuye ✅; bitandukanye ❌.
  4. Finish when all pairs are matched. Urangiza iyo amatsinda yose amaze guhuzwa.
Tip / Inama
Each new game uses a different combination of weather words, so you can learn more words.
Buri mukino ukoreshamo amagambo atandukanye y’ikirere kugira ngo wige menshi.
